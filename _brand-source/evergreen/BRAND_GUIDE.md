# Evergreen Legal AI: brand guide

**Name:** Evergreen Legal AI
**Endorsement line:** *Offered by Justin D Leigh PLLC*
**Mark:** the Quill Bough, a single fir branch drawn so it also reads as a quill pen. Evergreen (Washington, longevity) meets the written craft of law.

## Logo set (`assets/logo/`, outlined SVG + PNG in `png/`)

| File | Use |
|---|---|
| `evergreen-horizontal-*` | Default. Site headers, documents, email signatures |
| `evergreen-horizontal-offered-by-*` | Footers, proposals, anywhere the PLLC connection should be explicit |
| `evergreen-stacked-*` / `-offered-by-*` | Square-ish spaces, title slides, print |
| `evergreen-wordmark-*` | When the mark appears elsewhere on the page |
| `evergreen-mark-*` | Avatars, favicons, watermarks, small spaces |

Color variants: **color** (navy + teal, on white or light), **reversed** (white + light teal, on navy), **navy** (one color, light backgrounds), **white** (one color, dark or photo backgrounds).

- Clear space: at least the height of the "E" in Evergreen on all sides.
- Minimum size: horizontal logo 140px wide on screen; mark 24px (the favicon files use a simplified mark below 48px).
- Don't recolor, stretch, rotate, add effects, or set the wordmark in another font.

## Type

- **Cormorant Garamond 600** for display headlines and the wordmark. *Italic 500* for "Offered by…".
- **Manrope 400 / 600 / 700** for body, UI, and labels. Labels are uppercase, tracked at 0.42em ("LEGAL · AI").

## Voice

Measured, plain-spoken, practical. Write the way a careful lawyer explains technology: no hype, no guarantees, no "revolutionize."
